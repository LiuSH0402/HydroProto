# Data and code availability

For use after the v0.2.0 tag is publicly available:

The HydroProto source code, original fixed training and test datasets, and
additional grouped split and external evaluation dataset are publicly available
at https://github.com/LiuSH0402/HydroProto (version v0.2.0). The repository provides
sequence identifiers, amino acid sequences, class labels, partition assignments,
data provenance, filtering criteria, installation instructions and model
checkpoint download links. Project source code is distributed under the MIT
License. UniProt-derived data, pretrained backbones and the existing model
archive retain their respective source licenses.
