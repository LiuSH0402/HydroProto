# Changelog

## 0.2.0 — dataset and availability update prepared 2026-10-17

- Add MIT LICENSE, copyright Shang-Hua Liu and Ke-Jun Deng.
- Document sequence provenance, EC label mapping and filtering criteria.
- Add the 80%-component split of the unchanged original cohort.
- Add the 10,523-protein task-adapted external evaluation dataset, source fields,
  selection rules and dataset checksums.
- Preserve original training/test data, existing training code, results and
  model-download links. No new experiment code, predictions or statistical
  exports are included in this release.

The software/data version 0.2.0 is separate from the existing model archive's
version 1.0.0. A public version exists only after its Git commit/tag is pushed.
